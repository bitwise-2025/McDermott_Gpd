# 🔹 1. Microsoft Fabric Fundamentals

### Q1. What is Microsoft Fabric and how is it different from Synapse or ADF?

**Answer:**
Microsoft Fabric is an end-to-end analytics platform that unifies data engineering, data integration, data science, real-time analytics, and BI into a single SaaS environment. Unlike Synapse or ADF:

* It is **fully SaaS (no infrastructure management)**
* Uses **OneLake as a unified data lake**
* Integrates tools like Data Factory, Spark, Power BI, and Data Warehouse in one platform
* Provides **DirectLake mode** for real-time analytics

---

### Q2. What is OneLake and why is it important?

**Answer:**
OneLake is Fabric’s unified data lake storage:

* Acts as a **single source of truth**
* Supports **shortcutting** (linking external storage like ADLS)
* Eliminates data duplication
* Uses open formats like **Delta Lake**

---

### Q3. How would you migrate an ADF pipeline to Microsoft Fabric?

## Q1. How would you implement SCD Type 2 in Fabric using Delta Lake?

**Answer:**

Use Delta Lake `MERGE` with effective dates and flags.

```sql
MERGE INTO customer_target t
USING customer_source s
ON t.customer_id = s.customer_id AND t.is_current = true

WHEN MATCHED AND (
    t.name <> s.name OR t.city <> s.city
)
THEN UPDATE SET 
    t.is_current = false,
    t.end_date = current_timestamp()

WHEN NOT MATCHED 
THEN INSERT (
    customer_id, name, city, start_date, end_date, is_current
)
VALUES (
    s.customer_id, s.name, s.city, current_timestamp(), NULL, true
)
```

👉 Key points:

* Maintain `is_current`, `start_date`, `end_date`
* Insert new version + expire old one
